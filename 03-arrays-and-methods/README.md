## Методы перебора массивов:

* ### [Filter](01-filter-method.js) - фильтрация списков по условию (отсев мусора, дублей и тестовых записей).

**Зачем:** Чтобы из большого массива объектов от API оставить только те элементы, которые проходят проверку (например, только оплаченные и не тестовые заказы), не ломая исходный массив.

**Как работает:** Работает как фейсконтроль. Перебирает массив элемент за элементом и для каждого ожидает строго `true` (оставить) или `false` (выкинуть). Меняет **количество** элементов, но не меняет их внутреннюю структуру.

> [!WARNING]
> **Важно!** Нельзя перечислять несколько условий через запятую. Для объединения проверок используются только логические операторы: `&&` (логическое И) или `||` (логическое ИЛИ).

**Боевая формула:**
```javascript
const result = items.filter((item) => item?.status === "paid" && item?.is_test === false)
```

* ### [Map](02-map-method.js) - трансформация и нормализация каждого элемента массива в новую структуру данных.

**Зачем:** Чтобы превратить глубоко вложенный и «грязный» JSON от внешнего сервиса в плоские, аккуратные объекты с предсказуемыми полями, готовые для записи в базу данных (Supabase) или таблицу (Google Sheets).

**Как работает:** Берет каждый элемент исходного массива, прогоняет через функцию-преобразователь и собирает из результатов новый массив ровно такой же длины. Не меняет количество элементов, но полностью **пересобирает** их форму.

* **Короткая запись (без `{}`):** `items.map((el) => el.id)` - слово `return` срабатывает автоматически.
* **Блочная запись (с `{}`):** используется, когда внутри нужно создать переменные, безопасно вытащить поля через `?.` и подставить заглушки через `??` / `||`.

> [!WARNING]
> **Важно!** При использовании фигурных скобок `{ ... }` в теле `.map()` обязателен явный `return` в конце блока. Без него метод вернет массив из `[undefined, undefined, ...]`.

**Боевая формула:**
```javascript
const cleanList = rawItems.map((item) => {
  const name = item?.customer?.name || "Без имени"
  const sum = item?.payment?.amount ?? 0

  return {
    id: item.order_id,
    client: name,
    total: sum
  }
})
```

* ### [Method Chaining](03-method-chaining.js) - цепочки вызовов методов (конвейерная обработка списков без создания промежуточных переменных).

**Зачем:** Чтобы объединить несколько этапов обработки массива в один читаемый поток (например, сначала отфильтровать неактуальные товары, а затем сразу пересчитать цены у оставшихся), не засоряя код временными переменными вроде `filteredItems` или `mappedItems`.

**Как работает:** Каждый метод массива (`.filter()`, `.map()`) возвращает **новый массив**, поэтому следующий метод можно вызывать сразу через точку — он применится к результату работы предыдущего шага. Цепочка работает до тех пор, пока очередной метод возвращает массив.

> [!WARNING]
> **Важно! Два правила конвейера:**
> 1. **Порядок шагов:** всегда ставь `.filter()` **до** `.map()`. Если сначала пересобрать объекты через `.map()` и выбросить часть полей, следующий `.filter()` не сможет по ним отфильтровать.
> 2. **Приоритет операторов внутри расчетов:** у математических знаков (`-`, `+`, `*`, `/`) приоритет выше, чем у оператора `??`. Всегда бери страховку в круглые скобки: `basePrice - (discount ?? 0)`, иначе выражение сначала вычислит `250 - undefined` (получит `NaN`), и `?? 0` не сработает.

**Боевая формула:**

```javascript
const readyCatalog = products
  .filter((item) => item?.inStock === true && item?.basePrice > 100)
  .map((item) => ({
    id: item?.sku || "id not detected",
    name: item?.title || "name not detected",
    finalPrice: item?.basePrice - (item?.discount ?? 0)
  }))
