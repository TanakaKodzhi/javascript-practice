# Боевые шаблоны для ноды Code в n8n

Готовые, отказоустойчивые сниппеты на JavaScript (ES6+) для трансформации входящих данных от API и вебхуков внутри воркфлоу **n8n**.

## Содержание раздела

* **[01-each-item-telegram-webhook.js](01-each-item-telegram-webhook.js)** — парсинг входящего вебхука Telegram (режим *Run Once for Each Item*).

---

## Золотые правила ноды Code (Режим `Run Once for Each Item`)

В этом режиме n8n сам выступает в роли цикла: если на вход прилетело 10 элементов, скрипт запустится 10 раз — по одному разу для каждого объекта.

### 1. Контракт входа и выхода (Обязательная обертка)
n8n передает полезные данные внутри системной обертки `.json` и требует вернуть результат в таком же формате[cite: 1]:

```javascript
// 1. Распаковка входящего объекта
const item = $input.item.json;

// 2. Обратная упаковка (без ключа json нода упадет с ошибкой)
return {
  json: {
    ...item,
    processed: true
  }
};
