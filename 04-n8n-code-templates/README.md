# 📕 Шаблоны для ноды Code в n8n

Рабочие скрипты на JS для разбора входящих данных от API и вебхуков.

## Файлы

* **[01-each-item-telegram-webhook.js](01-each-item-telegram-webhook.js) - парсер входящего сообщения Telegram (режим *Run Once for Each Item*).**
* **[02-all-items-orders-filter-map.js](02-all-items-orders-filter-map.js) - фильтрация и нормализация списка заказов через `$input.all()`, `.filter()` и `.map()` (режим *Run Once for All Items*).**
* **[03-all-items-catalog-chaining.js](03-all-items-catalog-chaining.js) - конвейерная фильтрация каталога по наличию/цене и расчёт итоговой стоимости со скидкой через chaining `.filter().map()` (режим *Run Once for All Items*).**

---

## Памятка по режиму `Run Once for Each Item`

В этом режиме n8n сам прогоняет скрипт по очереди для каждого входящего элемента - циклы писать не нужно.

1. **Вход и выход:** данные всегда лежат в `$input.item.json`, а возвращать их нужно строго в обертке `{ json: { ... } }`, иначе нода упадет.
2. **Защита от пустоты:**
   * Верхний уровень забираем деструктуризацией со страховкой `= {}`.
   * Вглубь идем через `?.` (чтобы код не падал при отсутствии объекта) и `??` / `||` (чтобы поле не пропадало из JSON).
3. **Сборка ответа:**
   * `...obj` - разворачивает все поля на верхний уровень (удобно для записи в таблицы).
   * `obj` без точек - оставляет поля внутри вложенного объекта.

## Памятка по режиму `Run Once for All Items`

Используется, когда нужно работать сразу со всем массивом элементов (фильтровать список, склеивать данные, считать общую сумму).

1. **Вход:** весь массив входящих элементов забирается через `$input.all()`. Данные каждого элемента лежат внутри `.json` (`item.json`).
2. **Фильтрация и трансформация:**
   * `.filter()` меняет **количество** элементов (отсеивает мусор по условию `&&` / `||`), не меняя их структуру.
   * `.map()` **не меняет** количество элементов, но пересобирает каждый объект в новую плоскую форму.
3. **Выход:** внутри `.map()` каждый элемент обязан возвращаться в обертке `{ json: { ... } }`. В конце скрипта отдается сам итоговый массив (`return result;`) без дополнительных фигурных скобок и `...`.
