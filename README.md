## Инженерные принципы, которых я придерживаюсь в коде

* **Защита от падений (`?.` + `??`):** любой внешний JSON от стороннего API считается потенциально битым. Код не должен падать с `Cannot read properties of undefined`, а отсутствующие поля заменяются предсказуемыми заглушками.
* **Иммутабельность (`...`):** исходные объекты не перезаписываются напрямую - новые структуры собираются через распаковку.
* **Читаемая декомпозиция:** вместо многоуровневой вложенной деструктуризации - плоское извлечение верхнего уровня и короткие ссылки на вложенные блоки.
