* ### **[Оператор `?.`](Data-Structures/day2-optional-nullish.js) (Optional Chaining - безопасный переход)**
**Зачем:** Чтобы код не падал с ошибкой `Cannot read properties of undefined`, когда в JSON не хватает вложенных объектов.

**Как работает:** Ставится **перед** точкой (`user?.profile?.name`). Если `profile` нет, JS тормозит и спокойно отдает `undefined`.

>[!Warning]
>**Важно!** Не ставится в самом конце перед `??` (неправильно: `user?.name?. ?? "Нет", правильно: user?.name ?? "Нет"`).

* ### **[Оператор `??`](Data-Structures/day2-optional-nullish.js) (Nullish Coalescing - запасное значение)**
**Зачем:** Подменяет пустоту на нормальное значение по умолчанию, чтобы в базу или сообщение не улетело `undefined`.

**На что срабатывает:** ТОЛЬКО на `null` и `undefined`.

**Главное отличие от `||`:** Старый `||` считает число `0`, пустую строку `""` и `false` ложью и перезаписывает их. Оператор `??` сохраняет `0` и `false` как нормальные данные.
#### Боевая формула:
>```js
> const result = объект?.вложенность?.поле ?? "Запасное значение"
>```

* ### **[Деструктуризация](Data-Structures/day3-destructuring.js) (Destructuring - быстрая распаковка объектов)**

**Зачем:** Чтобы не писать десятки однотипных строчек `const name = obj.name`, а за один раз вытащить нужные поля из ветвистого JSON, переименовать их и защитить код от падения, если какого-то вложенного объекта нет.

**Как работает:** Пишем слева направо (сначала скелет `const { } = объект`), а читаем **справа налево** (из объекта справа достаём ключи в переменные слева):
* **Переименование (`:`):** `const { user_name: name } = user` - достаёт `user_name`, но создаёт переменную `name`.
* **Запасное значение (`=`):** `const { role = "user" } = user` - срабатывает **только** если поля нет или оно `undefined` (пустую строку `""`, `0` и `null` не перезаписывает).
* **Вложенность и страховка (`= {}`):** `const { club: { title = "Без клуба" } = {} } = player` - если самой коробки `club` нет, подставляется пустой объект `{}`, чтобы код не упал с ошибкой `Cannot destructure property ... of 'undefined'`.

> [!WARNING]
> **Важно!** При вложенной деструктуризации страховку `= {}` нужно ставить **после каждой** открытой вложенной коробки (`ключ: { ... } = {}`). Иначе при отсутствии внешнего объекта скрипт упадёт ещё до проверки значения по умолчанию.
