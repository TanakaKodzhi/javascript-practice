* ### **[Оператор `?.`](Data-Structures/day2-optional-nullish.js) (Optional Chaining - безопасный переход)**
**Зачем:** Чтобы код не падал с ошибкой `Cannot read properties of undefined`, когда в JSON не хватает вложенных объектов.

**Как работает:** Ставится **перед** точкой (`user?.profile?.name`). Если `profile` нет, JS тормозит и спокойно отдает `undefined`.

>[!Warning]
>**Важно!** Не ставится в самом конце перед `??` (неправильно: `user?.name?. ?? "Нет", правильно: user?.name ?? "Нет"`).

* ### **[Оператор `??`](Data-Structures/day2-optional-nullish.js) (Nullish Coalescing - запасное значение)**
**Зачем:** Подменяет пустоту на нормальное значение по умолчанию, чтобы в базу или сообщение не улетело `undefined`.

**На что срабатывает:** ТОЛЬКО на `null` и `undefined`.

**Главное отличие от `||`:** Старый `||` считает число `0`, пустую строку `""` и `false` ложью и перезаписывает их. Оператор `??` сохраняет `0` и `false` как нормальные данные.
#### Боевая формула:
>```js
> const result = объект?.вложенность?.поле ?? "Запасное значение"
>```
