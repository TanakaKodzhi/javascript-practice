## Инженерные принципы, которых я придерживаюсь в коде

* **Защита от падений ( `?.` + `??` / `||` ):** любой внешний JSON от стороннего API считается потенциально битым. Код не должен падать с `Cannot read properties of undefined`, а отсутствующие или пустые поля заменяются предсказуемыми заглушками.
* **Иммутабельность ( `...`, `.filter()`, `.map()` ):** исходные объекты и массивы не перезаписываются напрямую — новые структуры собираются через распаковку и декларативные методы.
* **Читаемая декомпозиция:** вместо многоуровневой вложенной деструктуризации — плоское извлечение верхнего уровня и короткие ссылки на вложенные блоки.
* **Нормализация на входе:** глубоко вложенные ответы от API сразу приводятся к плоскому объекту с единым контрактом полей, чтобы следующие ноды и таблицы получали предсказуемые данные.
